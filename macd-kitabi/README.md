# Sinyalin Ritmi — MACD'yi Sade Anlatım

Giriş ve orta seviye okuyucu için görsellerle desteklenmiş Türkçe MACD e-kitabı.

## Kitabı aç

Tarayıcıda şu dosyayı açın:

[`macd-kitabi/index.html`](index.html)

## İçerik

1. MACD nedir? (yakınsama / ıraksama)
2. Anatomi: MACD çizgisi, sinyal çizgisi, histogram
3. Formül (12, 26, 9)
4. Sinyal kesişimleri
5. Sıfır çizgisi
6. Histogram okuma
7. Uyumsuzluk (divergence)
8. Ayarlar ve zaman dilimleri
9. Pratik strateji iskeletleri
10. Sık hatalar
11. Diğer araçlarla birlikte kullanım
12. Özet + mini sözlük

## Görseller

`gorseller/` klasöründeki diyagramlar eğitim amaçlı üretilmiştir:

```bash
python3 macd-kitabi/scripts/generate_diagrams.py
```

Gereksinim: `matplotlib`
